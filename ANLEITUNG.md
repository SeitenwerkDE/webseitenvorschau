# Anesis Website – so kommt sie auf GitHub

Diese ZIP enthält die fertige Website für das GitHub-Projekt **Website-Reviewanesis3**
(Adresse: https://seitenwerkde.github.io/Website-Reviewanesis3/).

Wichtig: Die Website funktioniert nur online über die GitHub-Adresse,
nicht per Doppelklick auf index.html.

## Schritt für Schritt

1. ZIP entpacken (rechtsklick → Alle extrahieren).
2. GitHub-Projekt **Website-Reviewanesis3** öffnen.
3. Falls noch alte Dateien drin sind: alles löschen (drei Punkte neben jeder
   Datei → Delete), damit nichts doppelt ist.
4. `Add file` → `Upload files` → **nur den Ordner `assets`** (87 Dateien)
   hineinziehen → unten `Commit changes`.
5. Wieder `Add file` → `Upload files` → **alles Übrige** hineinziehen:
   index.html, 404.html, .nojekyll, favicon.png, robots.txt, sitemap.xml
   sowie die Ordner speisekarte, impressum, datenschutz, downloads
   → `Commit changes`.
   (GitHub nimmt maximal 100 Dateien pro Upload, deshalb die zwei Runden.)
6. 1–2 Minuten warten, dann https://seitenwerkde.github.io/Website-Reviewanesis3/
   öffnen und mit **Strg+F5** (Mac: Cmd+Shift+R) neu laden.

## Wichtig

- Die Datei **.nojekyll** (Punkt am Anfang!) muss mit hochgeladen werden.
  Sie ist auf vielen Computern ausgeblendet – unter Windows: Ansicht →
  Ausgeblendete Elemente aktivieren.
- Wenn du das GitHub-Projekt umbenennst oder ein neues anlegst, sag mir den
  neuen Namen – dann baue ich die Website dafür neu.

## Inhalt (97 Dateien)

- index.html (Startseite), 404.html (Fehlerseite)
- Ordner speisekarte, impressum, datenschutz (je eigene Seite)
- Ordner assets (87 Bilder, inkl. aller 16 Speisekarten-Seiten und Logo)
- Ordner downloads (Speisekarte als PDF)
- favicon.png (Browser-Symbol), robots.txt, sitemap.xml, .nojekyll
